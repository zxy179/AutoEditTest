## 项目简介

**AutoEditTest** 是一个面向文本驱动图像编辑模型的覆盖引导语义模糊测试框架。

文本驱动图像编辑模型根据自然语言指令生成编辑图像。然而，图像编辑结果具有开放性，通常不存在唯一正确输出。因此，如何自动生成有效测试用例、充分探索语义测试空间，以及在缺少真实参考图像的情况下判断编辑错误，仍然面临较大挑战。

## 方法框架

AutoEditTest 包含以下四个主要阶段：

### 1. 目标区域引导的上下文构建

检测并分割原始图像中的目标对象，结合目标类别、目标视觉描述和场景上下文，构建与目标区域相关的多模态信息，为后续生成编辑指令提供语义依据。

### 2. 可执行且可检查的编辑指令生成

结合目标区域上下文与编辑任务分类，生成自然语言编辑指令及其对应的结构化属性记录，保证测试输入具有较好的语义一致性、可执行性和可检查性。

### 3. 原子属性桶覆盖反馈

将编辑要求分解为对象、颜色、数量、材质、形状、大小和空间关系等原子语义属性，并统计不同属性值的覆盖情况。根据覆盖缺口优先探索尚未充分测试的语义空间。

### 4. 无真实参考图像的双分支测试预言机

通过两条互补分支自动检测图像编辑错误：

- **非目标区域保持性检测：** 判断与编辑任务无关的图像区域是否发生意外修改。
- **目标区域语义一致性检测：** 将编辑要求转换为结构化 Yes/No 视觉问答问题，判断编辑结果是否满足用户指令。
